# 2026-06-16: 캘린더 종일 일정 인접일 누수 수정 (KST 오늘만 수집)

## 배경

사용자 보고: 매일 TODO에 **엉뚱한 날 캘린더 항목이 섞임** (주로 어제 종일 일정).

## 진단

- 날짜는 이미 KST 정상: `main.py` `now = datetime.now(KST)`,
  `collect_calendar(now)`가 KST 00:00~다음날 00:00 검색창 사용
- cron도 KST 정렬 (`21 UTC = 06:00 KST`)
- caldav가 검색창 tz-aware datetime을 UTC로 정확히 변환 → 창 자체는 정확
- **근본 원인**: 종일 일정은 날짜만 있는 floating 값. 검색창을 UTC로 변환
  (KST 00:00 → 전날 15:00 UTC)하는 과정에서 어제 종일 일정 구간
  `[어제 00:00, 오늘 00:00)`이 오늘 창과 겹쳐 딸려 들어옴. 시간 지정 일정은
  창에 정확히 걸려 문제 없음.
