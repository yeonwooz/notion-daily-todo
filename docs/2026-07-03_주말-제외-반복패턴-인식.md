# 2026-07-03 "주말 제외" 반복 패턴 인식 수정

## 문제

`# 할 일` 섹션의 "매일 아침 할 일 (주말 제외)" 헤딩이 주말(토·일)에도 매칭되어
해당 반복 task가 매일 페이지에 들어갔다.

원인은 `heading_matches_today()`:
- `if "매일" in h: return True` — 뒤에 붙은 `(주말 제외)` 문구를 무시하고 무조건 True
- `if "주말" in h and weekday_idx >= 5: return True` — "주말 **제외**"의 "주말"에도 걸려
  주말에 True 반환 (두 번째 누수)

## 수정

`heading_matches_today()`에 주말 제외 명시 감지를 추가:

```python
is_weekend = weekday_idx >= 5
excludes_weekend = "주말 제외" in h or "주말제외" in h or "평일만" in h

if "매일" in h:
    return not (is_weekend and excludes_weekend)
...
if "주말" in h and not excludes_weekend and is_weekend:
    return True
```

- "매일 … (주말 제외)" → 평일만 매칭
- "주말 제외"/"주말제외"/"평일만" 문구를 인식
- 제외 문구 없는 "매일 …"은 기존대로 매일 매칭 (회귀 없음)

## 검증

`heading_matches_today` 단위 확인:
- "매일 아침 할 일 (주말 제외)": 금 True / 토·일 False / 월 True
- "매일 아침 할 일"(제외 문구 없음): 금·토 모두 True
- "주말 루틴": 금 False / 토 True
- "평일 스트레칭": 금 True / 토 False

## 참고

- 헤딩 이름은 그대로 두면 된다("월화수목금"으로 바꿀 필요 없음). 오히려 요일 매칭은
  `요일명 + "마다"` 조건이라 "월화수목금"은 매칭되지 않는다.
- Actions는 커밋된 코드로 돌므로 반영하려면 **push 필요**.
